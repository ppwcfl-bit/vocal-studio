# Vocal Studio

A singing and guitar instructor that runs in the browser: real pitch, chord and timing analysis from your microphone, songs to learn, and a conversational teacher.

- **Use it:** https://ppwcfl-bit.github.io/vocal-studio/ (add it to your home screen to install it like an app).
- **AI teacher (optional):** deploy `server/coach-worker.js` to Cloudflare Workers with your own Anthropic API key, then paste the worker URL into Settings → AI coach. The key stays on the server; it is never in this repository.
